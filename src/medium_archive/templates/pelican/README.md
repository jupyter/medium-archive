# A Pelican blog

Generated by `medium-archive pelican` from an archived Medium
publication. Self-contained: posts as CommonMark with YAML front
matter, their images, the theme, and the plugins for responsive images,
redirects, the sitemap and "More posts". Nothing to install beyond the
packages below, and ffmpeg.

## Build

```sh
pip install pelican markdown-it-py mdit-py-plugins pyyaml pillow
pelican                       # build into output/
pagefind --site output        # search index for /search/
pelican -l                    # build and serve at localhost:8000
```

Pillow provides image dimensions and responsive variants; without it
images are served as they are. `pagefind` (`npm install -g pagefind`)
is needed for search results.

ffmpeg, built with libx264, is needed for the animations. Each is kept
in `content/` as one master beside its `-poster.webp`: a lossless gif
or animated WebP, or an AV1 `.mp4` (4:4:4 color) where that is much
smaller. Every build makes the h264 served in `output/` from it,
cached under `cache/clips/` (or `$CLIP_CACHE`). The master is
the one copy to keep: a later change of served format is a change to
the plugin, not a new copy of every clip.

## What to edit

| file | contents |
|------|----------|
| `site.toml` | name, `base_url`, masthead, intro, footer, banner, newsletter, share image; every key is documented in the file |
| `data/tags.yaml` | tag slug → display name |
| `data/authors.yaml` | author slug → display name and optional profile URL |
| `content/posts/<year>/<slug>/index.md` | posts, with their images beside them |
| `theme/` | templates and stylesheet |
| `pelicanconf.py` | reader, URL scheme, feeds, plugins; holds no site data and is overwritten by every export |

Set `base_url` to the real domain: feeds, redirect stubs, Open Graph
tags and share links are built from it.

## Write a post

```
content/posts/2026/a-new-post/
  index.md
  images/diagram.png
```

```markdown
---
title: A new post
date: 2026-01-31 09:00
authors:
- ada-lovelace
tags:
- jupyter
subtitle: The line under the title, Markdown
summary: Card excerpt and meta description
cover: images/cover.jpg
---

The body, as CommonMark.

![a diagram]({attach}images/diagram.png)
```

- The URL is `/posts/<year of date>/<slug>/`. `slug` defaults to the
  directory name, used as is (not slugified), so keep directory names
  lowercase ASCII. Set `slug` to keep a URL when renaming a directory.
  The build reports posts whose directory year and date disagree or
  whose slug differs from the directory, and stops if two posts would
  write the same page.
- `/posts/<year>/` lists that year's posts automatically.
- `authors` and `tags` are slugs; names come from the data files, or
  the slug is shown.
- Dates are `YYYY-MM-DD HH:MM`, UTC. `modified:` sets the sitemap's
  last-modified date.
- Images need the `{attach}` prefix.
- `cover:` is the card and share image. Existing covers are the size
  in `site.toml`'s `cover_size`, which the pages declare; crop new
  covers to it or remove that key.
- Photographs get responsive variants; png and webp are treated as line
  art and served at full resolution.
- Captioned image: a `::: figure` directive with the caption as its
  body (see existing posts).

## Regenerating

`medium-archive pelican` overwrites the files it generates and leaves
others alone. While the site is still generated, make corrections in
the archive (`site/site.toml`, `archive/tags.json`, the post). Once this
directory is its own repository (`medium-archive pelican --out DIR`;
`--clean` removes pages the archive no longer has, keeping `.git/` and
ignored files), edit the files here.
